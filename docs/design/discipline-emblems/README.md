# Combat Shadow Studio — emblèmes disciplines (proposition vectorielle)

Branche de travail : `design/premium-discipline-emblems`.

Ce dossier contient six **emblèmes SVG vectoriels originaux** (128 × 128 viewBox) :

- `boxing.svg` — Boxe anglaise : gants rouges
- `kickboxing.svg` — Kick-boxing : protège-tibias noirs/rouges
- `mma.svg` — MMA : gant à doigts ouverts
- `muaythai.svg` — Muay-thaï : mongkhon tressé
- `bjj.svg` — Jiu-jitsu brésilien : ceinture noire avec bande rouge
- `judo.svg` — Judo : judogi blanc et ceinture noire

## Statut et limites

**Propositions vectorielles simplifiées, pas extraction fidèle des objets 3D de la planche approuvée.** La planche photoréaliste créée dans ChatGPT n'a pas été intégrée comme image binaire au dépôt. Ne pas présenter ces SVG comme les rendus 3D approuvés ; ils servent de première base vectorielle à comparer et à retravailler.

Les icônes sont autonomes, sans police ni ressource externe. Elles peuvent être utilisées comme prototypes de variante semi-flat après validation visuelle. Le lot final nécessitera les véritables rendus détaillés isolés, détourés, exportés en WebP/PNG transparents, ainsi que des variantes contour et les tests de lisibilité à 24/32/64/128 px.

Ne pas modifier les coachs 3D, les animations, la navigation ou les données utilisateur pour intégrer ces ressources.
