# Mandatory real-time on-device neural correction — prototype only

A mandatory 5→12→4 tiny neural network, trained with synthetic teacher examples, executes *synchronously once per animation frame* in `src/lab/Fighter.tsx`, before the geometry-specific two-bone IK solver and contact locks. 12 tanh hidden activations and four bounded output channels correct hip, torso, pivot and hand height. No cloud, no network, no Python and no ONNX runtime dependency at playback time. This fits an Android WebView; still benchmark actual Android hardware.

**Scope:** This is a genuine numerical neural network with trained weights, but its examples are synthetic and deliberately simple. It is NOT trained on real martial athletes, is NOT proof of physical correctness, and does NOT yet meet the requested ultimate human realism. Its primary purpose is to guarantee that the mandatory real-time AI architecture, frame-by-frame inference and safety projection are in place **now**. All weights are reproducible with `training/train_synthetic.py` and are frozen in `src/core/neural.ts`.

**Next required improvement:** train on properly licensed martial-arts MoCap, with features including full skeleton pose history, joint angular velocities, ground contact, COM and technique phase. Quantize/compile an ONNX model, use local WebAssembly/WebGPU inference and *keep a bounded synchronous neural controller* in the render loop; use double-buffering for expensive model inference only after it passes latency tests. Do not promise 60 fps or use multi-GB models at runtime without measurements.

**Relevant research:** NVIDIA ARDY (real-time but expensive desktop-scale inference), https://github.com/nv-tlabs/ardy ; Kimodo (high-fidelity offline), https://github.com/nv-tlabs/kimodo ; ONNX Runtime Web https://github.com/microsoft/onnxruntime .
